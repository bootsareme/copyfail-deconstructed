# copyfail-deconstructed
Easy to understand version of [CVE-2026-31431](https://nvd.nist.gov/vuln/detail/CVE-2026-31431). The original proof-of-concept is found here: https://github.com/theori-io/copy-fail-CVE-2026-31431, but is minified so it can run in as small of a footprint as possible. This repository attempts to break down the code in a more readable manner, including what the code does and how to target different platforms. See the more technical writeup here: https://xint.io/blog/copy-fail-linux-distributions.
